## 𐑪𐑤𐑦𐑜𐑬𐑡𐑦𐑟 (Layouts)

𐑓𐑦𐑕 𐑮𐑦𐑪𐑴𐑟𐑦𐑡𐑹𐑦 𐑨𐑩𐑯𐑑𐑱𐑯𐑟 𐑨𐑳𐑕𐑑𐑩𐑥 𐑯𐑰𐑚𐑹𐑛 𐑪𐑤𐑦𐑜𐑬𐑡𐑦𐑟 𐑓𐑹 𐑩 𐑐𐑤𐑨𐑯𐑨 𐑹𐑔𐑩𐑤𐑦𐑯𐑾𐑮 𐑯𐑰𐑚𐑹𐑛.

𐑪𐑤 𐑛𐑦𐑮𐑦𐑨𐑑𐑩𐑮𐑦𐑟 𐑤𐑦𐑕𐑑𐑩𐑛 𐑚𐑦𐑤𐑴 𐑿𐑑𐑦𐑤𐑲𐑟 𐑞 𐑦𐑜𐑟𐑨𐑨𐑑 𐑕𐑱𐑥 𐑷𐑮𐑛𐑢𐑺 𐑚𐑱𐑕 (Planck v6, 48-key layout):

* **𐑓𐑮𐑨𐑯𐑨𐑩𐑯-𐑐𐑤𐑨𐑯𐑨 (Franken-Planck):** 𐑩 9-𐑤𐑱𐑩𐑮 𐑪𐑤𐑦𐑜𐑬𐑡 𐑓𐑰𐑑𐑿𐑮𐑦𐑯 𐑞 𐑓𐑪𐑤𐑴𐑦𐑯 𐑓𐑳𐑯𐑨𐑿𐑯𐑩𐑤 𐑨𐑱𐑐𐑩𐑚𐑦𐑤𐑦𐑑𐑦𐑟:
  * `hjkl` 𐑨𐑿𐑮𐑕𐑩𐑮 𐑯𐑰𐑟 (Vim-style) 𐑐𐑩𐑟𐑦𐑿𐑯𐑩𐑛 𐑳𐑯𐑛𐑩𐑮 𐑞 Lower 𐑤𐑱𐑩𐑮 (𐑷𐑴𐑤𐑛𐑦𐑯 𐑞 𐑯𐑰𐑟 𐑑𐑮𐑦𐑜𐑩𐑮𐑟 𐑮𐑦𐑐𐑰𐑑𐑦𐑯 𐑨𐑮𐑴𐑟).
  * Home-row modifiers.
  * 𐑤𐑦𐑓𐑑-𐑷𐑨𐑯𐑛𐑩𐑛 num-pad 𐑨𐑯𐑛 𐑮𐑲𐑑-𐑷𐑨𐑯𐑛𐑩𐑛 mouse-pad.
  * 𐑩 𐑛𐑦𐑛𐑦𐑨𐑱𐑑𐑩𐑛 𐑤𐑱𐑩𐑮 𐑨𐑩𐑯𐑑𐑱𐑯𐑦𐑯 𐑪𐑤 24 𐑓𐑳𐑯𐑨𐑿𐑯 𐑯𐑰𐑟.
  * Media keys 𐑨𐑯𐑛 𐑨𐑐𐑤𐑦𐑨𐑱𐑿𐑯 𐑤𐑷𐑯𐑨𐑩𐑮𐑟 (𐑪𐑐𐑑𐑦𐑥𐑲𐑟𐑛 𐑓𐑹 AutoHotkey 𐑦𐑯𐑑𐑦𐑜𐑮𐑱𐑿𐑯 𐑓𐑲𐑩 𐑱𐑿𐑩𐑯 𐑤𐑨𐑯𐑜𐑢𐑦𐑡 𐑯𐑰𐑟 𐑥𐑨𐑐𐑩𐑛 𐑪𐑯 𐑞 𐑥𐑬𐑕 𐑤𐑱𐑩𐑮).
  * 𐑛𐑦𐑮𐑦𐑨𐑑 𐑨𐑨𐑕𐑦𐑕 𐑑𐑪 𐑑𐑦𐑤𐑛𐑩, backtick, 𐑨𐑯𐑛 𐑨𐑢𐑴𐑑𐑕 𐑪𐑯 𐑤𐑱𐑩𐑮 0 (𐑚𐑲𐑐𐑨𐑕𐑦𐑯 𐑤𐑱𐑩𐑮-𐑑𐑨𐑐 𐑮𐑦𐑕𐑑𐑮𐑦𐑨𐑿𐑯𐑟).
  * 𐑻𐑜𐑩𐑯𐑪𐑥𐑦𐑨 𐑔𐑳𐑥 𐑨𐑩𐑯𐑑𐑮𐑴𐑤: 𐑑𐑨𐑐𐑦𐑯 Raise 𐑦𐑜𐑟𐑦𐑨𐑿𐑑𐑕 Backspace, 𐑑𐑨𐑐𐑦𐑯 Lower 𐑦𐑜𐑟𐑦𐑨𐑿𐑑𐑕 Delete.
  * 𐑦𐑯𐑑𐑦𐑜𐑮𐑱𐑿𐑯 𐑪𐑓 𐑞 𐑻𐑜𐑩𐑯𐑪𐑥𐑦𐑨 NEO2 𐑪𐑤𐑦𐑜𐑬𐑡 (𐑪𐑐𐑑𐑦𐑥𐑲𐑟𐑛 𐑓𐑹 𐑐𐑮𐑴𐑜𐑮𐑨𐑥𐑦𐑯 𐑨𐑯𐑛 𐑥𐑨𐑔𐑩𐑥𐑨𐑑𐑦𐑨𐑩𐑤 𐑕𐑦𐑯𐑑𐑨𐑨𐑕), 𐑢𐑺 𐑞 𐑳𐑥𐑤𐑬𐑑𐑕 𐑷𐑨𐑓 𐑚𐑰𐑯 𐑮𐑦𐑥𐑨𐑐𐑩𐑛 𐑑𐑪 𐑛𐑳𐑚𐑩𐑤 𐑨𐑢𐑴𐑑𐑕 𐑨𐑯𐑛 𐑩 𐑨𐑴𐑤𐑩𐑯/𐑕𐑦𐑥𐑦𐑨𐑴𐑤𐑩𐑯.
* **𐑨𐑯𐑡𐑦𐑤𐑩𐑟 𐑓𐑮𐑨𐑯𐑨𐑩𐑯-𐑐𐑤𐑨𐑯𐑨:** 𐑩 𐑓𐑺𐑦𐑱𐑿𐑯 𐑪𐑓 𐑞 𐑓𐑮𐑨𐑯𐑨𐑩𐑯-𐑐𐑤𐑨𐑯𐑨 𐑪𐑤𐑦𐑜𐑬𐑡, 𐑑𐑱𐑤𐑩𐑮𐑛 𐑕𐑐𐑦𐑕𐑦𐑓𐑦𐑨𐑩𐑤𐑦 𐑓𐑹 𐑨𐑯𐑡𐑦𐑤𐑩.
* **𐑥𐑨𐑨𐑮𐑴𐑐𐑨𐑛 𐑨𐑯𐑡𐑦𐑤𐑩:** 𐑩 𐑥𐑨𐑨𐑮𐑴-𐑐𐑨𐑛 𐑨𐑩𐑯𐑓𐑦𐑜𐑿𐑮𐑱𐑿𐑯 𐑞𐑨𐑑 𐑤𐑪𐑡𐑦𐑨𐑩𐑤𐑦 𐑪𐑐𐑩𐑮𐑱𐑑𐑕 𐑨𐑟 𐑩 𐑐𐑤𐑨𐑯𐑨 𐑯𐑰𐑚𐑹𐑛.
